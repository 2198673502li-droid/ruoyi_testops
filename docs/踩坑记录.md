## 已预判的高危坑（来自任务书 §9，待亲自验证后转成上表条目）

| 坑 | 症状 | 解法要点 |
|---|---|---|
| 验证码 | `/login` 返回"验证码错误/已失效" | 改 `sys_config.sys.account.captchaEnabled=false`，再 `/system/config/refreshCache` 或重启后端 |
| Bearer 格式 | 401「认证失败」 | `Authorization: Bearer <token>`，**Bearer 后有一个空格** |
| 登出污染 | 登出用例跑完，后续接口全 401 | session 级 token 不用于 `/logout`，登出类用例单独 `fresh_token` |
| 密码错误锁定 | 连错 5 次 admin 被锁 10 分钟，整轮回归崩 | 锁定/禁用类用例只用专用账号 `autotest`；应急 `redis-cli del pwd_err_cnt:admin` |
| Long 变字符串 | `assert data.userId == 1` 失败，实际 `"1"` | 统一 `str()` 比较 |
| MySQL 初始化只跑一次 | 改了 init SQL 但库里没变 | `/docker-entrypoint-initdb.d/` 仅在数据目录为空时执行，需 `down -v` 重建 |
| 容器内 127.0.0.1 | 后端连不上 MySQL | 容器里 localhost 是自己，必须用服务名 `mysql:3306` |
| bind mount 静默失败 | 容器起来了但库里没表 / nginx 403 | docker.sock 场景路径由宿主解析，改 `COPY` 进镜像 |
