# 接口清单（RuoYi-Vue）

> 用途：接口自动化用例的"需求底稿"。`权限点` 取自 Controller 上的 `@PreAuthorize("@ss.hasPermi('...')")`。
> 状态：认证模块已对源码核对（2026-11-09）。
> 约定：GET 用 `params=`，POST/PUT 用 `json=`；分页固定 `pageNum` / `pageSize`；时间范围用 `params[beginTime]` / `params[endTime]`（`yyyy-MM-dd`）。

### A3 POST /logout

不是 Controller 方法，由 Spring Security 的 LogoutFilter + LogoutSuccessHandlerImpl 实现，永远返回成功。

| 项 | 内容 |
|---|---|
| 鉴权 | 由 ruoyi-framework/src/main/java/com/ruoyi/framework/config/SecurityConfig.java:111` `.logout(logout -> logout.logoutUrl("/logout").logoutSuccessHandler(logoutSuccessHandler))` 接管。LogoutFilter 排在鉴权过滤器之前，所以**未登录也能调用**；ruoyi-framework/src/main/java/com/ruoyi/framework/config/SecurityConfig.java:108` 的 `anyRequest().authenticated()` 管不到它（实测无 token 也返回 200）。token 校验逻辑同 ruoyi-framework/src/main/java/com/ruoyi/framework/security/filter/JwtAuthenticationTokenFilter.java:34-41`，但这里不拦请求 |
| 请求字段 | 无 body、无 query（ruoyi-framework/src/main/java/com/ruoyi/framework/security/handle/LogoutSuccessHandlerImpl.java:39` 只用 request 取 token）。仅 Header `Authorization: Bearer <token>`（ruoyi-admin/src/main/resources/application.yml:98` `header: Authorization`；ruoyi-framework/src/main/java/com/ruoyi/framework/web/service/TokenService.java:219-227` 去 `Bearer ` 前缀，ruoyi-common/src/main/java/com/ruoyi/common/constant/Constants.java:106` `TOKEN_PREFIX="Bearer "`） |
| 成功判据 | body `code=200` + `msg="退出成功"`（ruoyi-framework/src/main/java/com/ruoyi/framework/security/handle/LogoutSuccessHandlerImpl.java:51` 直接 `ServletUtils.renderString` 输出 `AjaxResult.success("退出成功")`）。**注意：有没有有效 token 都是 200**，不能拿它当“token 有效”的判据 |
| 失败情形 | HTTP 层没有失败分支：无 token、乱 token（`Bearer garbage.token.value`）、已过期 token 一律返回 `{"code":200,"msg":"退出成功"}`（均实测）；`GET /logout` 也是 200（实测），因为 CSRF 已禁用（ruoyi-framework/src/main/java/com/ruoyi/framework/config/SecurityConfig.java:90`），LogoutFilter 不限定方法。唯一“什么都不做”的情况是 token 解析不出 LoginUser，直接跳过删缓存与写日志（ruoyi-framework/src/main/java/com/ruoyi/framework/security/handle/LogoutSuccessHandlerImpl.java:43-50`） |
| 前置与副作用 | 有效 token 时：删 Redis `login_tokens:{uuid}`（ruoyi-framework/src/main/java/com/ruoyi/framework/security/handle/LogoutSuccessHandlerImpl.java:47` → ruoyi-framework/src/main/java/com/ruoyi/framework/web/service/TokenService.java:100-107`）；异步写 `sys_logininfor` 一条 `Logout` 记录（ruoyi-framework/src/main/java/com/ruoyi/framework/security/handle/LogoutSuccessHandlerImpl.java:49`，ruoyi-common/src/main/java/com/ruoyi/common/constant/Constants.java:61` `LOGOUT="Logout"`）。无 token 时两者都不发生，仍返回成功 |
| 源码 | `ruoyi-framework/src/main/java/com/ruoyi/framework/config/SecurityConfig.java:111`；`ruoyi-framework/src/main/java/com/ruoyi/framework/security/handle/LogoutSuccessHandlerImpl.java:39-52`（`SysLoginController.java` 里确实没有 logout 方法） |
| 实测 | 实测 2026-11-09：`POST /logout` 带刚登录的 token → `{"msg":"退出成功","code":200}`；同一 token 再 `GET /getInfo` → `{"code":401,...}`（缓存已删）。对照：不带 token、带乱 token 的 `POST /logout` 均为 `{"code":200,"msg":"退出成功"}`；`GET /logout` 同样 200 |

### U12 PUT /system/user/profile/updatePwd

| 项 | 内容 |

| 鉴权 | **无 `@PreAuthorize`**，登录即可（`ruoyi-admin/src/main/java/com/ruoyi/web/controller/system/SysProfileController.java:91-93`，类级 `@RequestMapping("/system/user/profile")` 在第 35 行）；未登录被 ruoyi-framework/src/main/java/com/ruoyi/framework/config/SecurityConfig.java:108` 拦成 401；`@Log(title = "个人信息", businessType = BusinessType.UPDATE)`（第 91 行） |
